TEAM PHOTOS
===========

Drop a photo here for each team and it appears as a banner ABOVE that team's
roster on teams.html. Missing photos fall back to a gold monogram of the
players' initials, so nothing breaks if a photo is absent.

Filename convention:  teams/<team-code>.jpg

The team code is the slug of the two player names: lowercase, spaces/accents/
punctuation stripped, joined by a hyphen  →  player1-player2.

  8. Ale & Marcin       → teams/ale-marcin.jpg
  9. Martin & Sayor     → teams/martin-sayor.jpg
 10. Nathaniel & Toni   → teams/nathaniel-toni.jpg

IMPORTANT: the code is derived from the names EXACTLY as you type them in the
Sheet's "Teams" tab. Change a name and the code/filename changes with it (e.g.
"Nat" instead of "Nathaniel" → nat-toni, so the file must be teams/nat-toni.jpg).
Keep the names in the Teams tab, the image filenames, and the PoolMatches/
Knockout home/away columns all using the same code so everything lines up.

You can also override the auto code by adding a `code` column in the Teams tab.

Recommended: landscape JPGs, ~800px wide, kept small (<200 KB). The banner crops
to a 16:11 ratio (object-fit: cover), centred — keep faces near the middle.
